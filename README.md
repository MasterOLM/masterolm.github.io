# masterolm.github.io

Статичный сайт-визитка (GitHub Pages, без сборки): `index.html` + `assets/`.

## Публикация

Опубликованный адрес: <https://masterolm.github.io/>

Ветка `main`, корень репозитория — Pages отдаёт файлы как есть. В Settings → Pages источник должен быть
`Deploy from a branch` → `main` → `/ (root)`. Сборка Jekyll отключена файлом `.nojekyll`.

## Свой домен

1. В Settings → Pages → Custom domain вписать домен (например `example.ru`), сохранить.
2. У регистратора/в DNS:
   - для апекса (`example.ru`): `A` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - для `www`: `CNAME` → `masterolm.github.io`.
3. В репозиторий добавить файл `CNAME` с одной строкой — именем домена (без `https://` и без слэша).
4. Дождаться выпуска сертификата и включить `Enforce HTTPS`.

## Структура

- `index.html` — визитка: услуги, карточка продукта, контакты
- `product.html` — страница продукта «Обмен JSON» (что переносится, возможности, схема работы, скриншоты, видео, цены, требования, условия лицензии)
- `purchase.html` — «Как купить»: порядок работы, что нужно от клиента, документы, что не входит
- `terms.html` — публичная оферта (лицензионное соглашение): объём лицензии, запреты, оплата, обновления, ответственность, возврат
- `privacy.html` — политика обработки персональных данных (152-ФЗ)
- `404.html` — страница «не найдено»
- `assets/style.css` — общая тема; `assets/product.css` — продукт; `assets/legal.css` — юридические страницы и «Как купить»
- `assets/main.js` — переключатель RU/EN (язык в `localStorage`, принудительно — `?lang=en`)
- `assets/product/*.png` — скриншоты для страницы продукта
- `favicon.svg`, `.nojekyll`, `.gitattributes`

## Правка содержимого

- Тексты — прямо в `index.html`, `product.html`, `purchase.html`; двуязычные блоки помечены классами `i18n-ru` / `i18n-en`
  (видимостью управляет атрибут `lang` на `<html>`). Юридические страницы (`terms.html`, `privacy.html`) — только на русском,
  в EN-режиме показывают пометку, что действует русская редакция.
- Заголовок вкладки на каждой странице свой: атрибуты `data-title-ru` / `data-title-en` на `<html>` (или `data-static-title`).
- Ссылки на видео — в блоке «Видео-демо» (`product.html`, ссылки YouTube и RuTube).
- Стили — `assets/style.css` (общая тема, переменные в `:root`, `--accent` — акцентный цвет), `assets/product.css`, `assets/legal.css`.

## Локальный просмотр

Просто открыть `index.html` в браузере. Для проверки как на Pages (нужны корректные 404 и «чистые» URL) — любой статический
сервер; в VS Code удобно расширением **Live Preview** (ПКМ по `index.html` → *Show Preview*). Python/Node в системе не установлены.
